# Take on Transplant Project Site

## To test/view site locally

1. In stall Python 3
2. Run python3 -m http.server 8000
3. Go to http://localhost:8000/ 


## To manage translations
1. add attributes, data-i18n, or data-i18n-html(for text containing HTML) for newly added element(s)
2. update `js/translations.json`
